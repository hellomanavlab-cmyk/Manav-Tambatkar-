# MANAV Portfolio

A standalone, responsive static portfolio website for Manav Tambatkar.

## Run locally
Open `index.html` in a browser. For local development, you can also run:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Deploy
This is a static site. Upload the project folder to a new GitHub repository and import that repository into Vercel, or deploy the folder using any static hosting provider. Keep it as a separate project so the existing portfolio remains untouched.

## Before publishing
- Confirm the ZYRVON official URL and add it in `index.html`.
- Add real project screenshots and verified project links to the Work section.
- Add genuine certificates only when you have them. No n8n certificate is included.
- The contact form opens the visitor's email app using `mailto:`. It does not store or send data through a backend.
- Review all social and venture links before publishing.

## Files
- `index.html` — page content and sections
- `style.css` — responsive design
- `script.js` — mobile navigation and email form
- `assets/manav-portrait.png` — supplied portrait photo
